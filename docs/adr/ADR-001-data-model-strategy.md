#ADR-001 — Data Model Strategy


Decisão: utilizar tabelas próprias do EMS (ZEMST_*) em vez de persistir diretamente em tabelas standard SAP como EBAN.


Motivação: manter o projeto independente, controlável e focado no aprendizado de RAP, permitindo integração futura com objetos standard sem acoplamento prematuro.


Status: Accepted.
