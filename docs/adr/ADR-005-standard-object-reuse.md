# ADR-005 — Standard Object Reuse

Decisão: reutilizar Data Elements e tipos standard SAP sempre que o significado funcional coincidir.


Exemplos:

- BUKRS
- WERKS_D
- MATNR
- MEINS
- WAERS
- SYUNAME
- BNFPO


Objetos ZEMSE_* serão criados apenas quando houver semântica específica do EMS.


Status: Accepted.
